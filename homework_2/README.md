# Homework 2

Setup and run (from this directory):

    pip install -r requirements.txt
    bash run_all.sh

Each notebook is self-contained and reads its data from this directory.

- hw2_q1.ipynb: Gaussian MLP on NYC taxi trips (taxi_trips.parquet)
- hw2_q2.ipynb: categorical encodings on retail.csv
- hw2_q3.ipynb: Random Kitchen Sinks vs. MLP (train/val/test.csv); writes rks_test_predictions.csv and mlp_test_predictions.csv
